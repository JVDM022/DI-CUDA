# Kamiak desktop launcher

These existing tools submit indexing jobs to Kamiak. For the **local app**, use
[Start Indexing Studio](../app/README.md) instead.

- `Kamiak DI.app`, `Kamiak DI.command`: macOS Kamiak launchers.
- `Kamiak DI.cmd`: Windows Kamiak launcher.
- `kamiak_di.py`: desktop interface and submission logic.
- `queue_run.sh`, `setup.slurm`: cluster preparation helpers.
- `build_portable.py`: existing portable-package builder.

See the [HPC guide](../docs/HPC_GUIDE.md) for prerequisites and usage. No new
Windows executable was produced during the stopped packaging attempt.
